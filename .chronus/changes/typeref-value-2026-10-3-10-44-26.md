Handle compile-time type-reference scalars without treating them as runtime values. GraphQL reports references used in emitted fields, parameters, and return types. JSON Schema reports unserializable defaults and examples; OpenAPI reports unserializable examples instead of crashing. JSON Schema and OpenAPI represent reference types as accepting no JSON values.
