# TypeSpec authoring

Review the attached TypeSpec document and help the user continue authoring it.

1. Preserve the user's intent and follow conventions in nearby `.tsp` files.
2. Use diagnostics and the owning package's existing tests or compile scripts to validate changes.
3. Keep edits focused and explain any diagnostics that cannot be resolved safely.
